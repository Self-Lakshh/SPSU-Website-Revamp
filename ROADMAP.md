# SPSU-Website-Revamp Roadmap

## Vision
To build a modern, premium, and highly performant university website using React, Firebase, and Tailwind CSS.

## Milestones

1. **M1: Architecture & Foundation (Week 1-2)**
   - Setup React + Vite + Tailwind + shadcn/ui.
   - Configure Firebase Auth, Firestore, and Storage.
   - Establish routing, layout shell, and global design tokens.

2. **M2: Public Interface (Week 3-10)**
   - Build out premium Homepage with Framer Motion animations.
   - Implement Academic, Admissions, Faculty, and Placement portals.
   - Develop responsive layout and robust a11y implementation.

3. **M3: Admin CMS (Week 11-18)**
   - Role-based Dashboard.
   - CRUD interfaces for dynamic content (News, Events, Faculty, Gallery).
   - Form handling and enquiry management.

4. **M4: Polish & Deploy (Week 19-24)**
   - Performance tuning (lazy loading, caching).
   - SEO optimization.
   - Final review and handoff.
